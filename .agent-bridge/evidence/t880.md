# 入口 HTML 显式路由禁 304（task_id: t880 续跑轮）

> 根因：仅中间件设 `Cache-Control: no-store` 不够；`StaticFiles(html=True)` 仍对条件请求返回 304，浏览器继续用旧 index。改法：在 mount 之前注册显式 `GET /` → `HTMLResponse`（`no-store` + `Pragma: no-cache`），不参与 ETag/IMS 协商。

```bash
# 退出码：0

```

## b. 改动文件清单

- `app/main.py`：dist 存在时，在 `app.mount("/", StaticFiles(...))` **之前**新增 `@app.get("/")` 读 `_WEB_DIST/index.html` 并返回 `HTMLResponse`（`Cache-Control: no-store`、`Pragma: no-cache`）；dist 不存在时仍走原内联 fallback；`/assets/*` immutable 中间件未改
- 桥接产物：`AGENT_BRIDGE_PROGRESS.md`、`AGENT_BRIDGE_EVIDENCE.md`、`.agent-bridge/evidence/t880.md`
