### 分页参数（静态核对）

- 默认 `detailPageSize = 20`；`page-sizes = [20, 50, 100]`。
- 区间文案：`共 {{ detailFilteredDevices.length }} 台，第 {{ detailRangeStart }}-{{ detailRangeEnd }} 台`。
- tab 计数基于 `detailBaseDevices`（当前品类/全部设备的原始集合），与搜索无关。
- 页码重置：`watch([selectedDeviceType, detailStatusTab, deviceSearch]) => detailPage = 1`；`pageSize` 或结果长度变化时仅将页码收敛到有效范围，避免空白页。
- 搜索命中提示：`匹配 {{ detailFilteredDevices.length }} 台`。

### 交互实现要点

- 概况统计卡：`@click="openOverviewStat('all'|'available'|'occupied'|'offline'|'pending')"`，统一调用 `openDeviceDetail(ALL_DEVICES, status)`。
- 品类卡：保留 `el-card @click="openDeviceType(g.type)"`（el-card 根节点绑定，内边距与 el-tag 子元素点击均冒泡到根节点，事件透传可靠），并补 `cursor:pointer` + hover 阴影/边框高亮。
- 表格：`height="min(70vh, 640px)"`，依赖 el-table 内置 sticky header；`fixed="right"` 操作列保留。
- 空态：`el-empty description="该状态下没有设备"`。
