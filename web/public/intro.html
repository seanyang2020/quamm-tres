1. 系统定位

Quamm TRES 统一管理公司 ADB 测试设备，解决设备占用不透明、闲置难回收、凭据失控三类问题。 AI Agent 经 MCP 申请、续约、心跳、释放设备；管理员与用户经 Web 查看占用、巡检与凭据。 数据库是唯一事实源，后台 Worker 用服务器时钟持续对账，重启不丢租约。

一套 rr_ 凭据 · Web/MCP 两用 admin / user 两档权限 逻辑 + 物理双闸门防闲置 凭据全生命周期可管

5. 申请 → 心跳 → 锁 → 回收

res_apply必带 agent_info
→
发租约 + 心跳契约含锁路径
→
adb connect + 写 RAMFS 锁主机时钟
→
每 75 分钟 res_heartbeat续约，受 24h 上限
→
超时/到期 → 删锁 + 断 ADB

Agent 自维护锁、缺失即补；遇到 foreign lock 不自行删除，由服务端裁决。

7. 防闲置两道闸门

逻辑闸门Worker 每 10 秒用服务器时钟比对：TTL 到期或心跳超时即强制回收，不依赖 Agent 自觉。

物理闸门回收时校验锁 holder/lease 匹配后删除 RAMFS 锁并 adb disconnect，旧 Agent 物理上无法继续操作。

8. 凭据生命周期（v0.19 重点）

发放 issue有效期 90 天
→
吊销 revoke级联强制回收活跃租约
→
恢复 restore清空吊销时间

普通删除 delete

仍有租约引用时以 409 CREDENTIAL_IN_USE 拒绝，保护历史。

强制删除 force-delete（管理员）

先回收活跃租约，再硬删凭据并级联删除关联租约 / 排队条目，全程留审计。Web 与 MCP 均支持。

已吊销凭据在 Web 单独的「已吊销」标签页展示，不占用有效凭据主表。
